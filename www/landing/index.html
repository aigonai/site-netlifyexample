How it works

Three steps from an idea to a link

  1. 01

    Describe it

    Say what the tool should do and who uses it. Claude Code writes the page, the styles and the script.

  2. 02

    Keep it in a folder

    One repository, one www folder. The build script turns Markdown and templates into plain HTML.

  3. 03

    Publish it

    Connect the repository to Netlify. Every push to main is live in under a minute.

What you get

What a static site gives you

  • Nothing to keep running

    Netlify serves files. There is no server of yours to patch or restart.

  • Fast everywhere

    Pages come from a CDN close to the reader, with long caching on every asset.

  • Readable by people and by LLMs

    Each page has a Markdown twin, served to any client that asks for text/markdown.

  • Yours to change

    The whole site is a folder of text files under version control.

Questions

Questions people ask

Do I need to know HTML?

No. You describe what you want and read what comes back. Knowing where things live helps, and the repository is laid out so that it is easy to see.

What does Netlify cost for a site like this?

A small static site fits in Netlify's free tier. Check their current limits for bandwidth and build minutes.

Can it have a form?

Yes. The one at the bottom of this page is collected by Netlify Forms, from a plain HTML form, with no code of your own on a server.

Where does the copy on this page come from?

From the front matter of content/landing/index.md, which is never published. Change the text there and rebuild.
