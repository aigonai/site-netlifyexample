Worked examples

Three sites and an app on Netlify

A landing page, a multi-page website, a blog and a web app. One repository, plain files on Netlify. Pick the one closest to what you need and copy its folder.

Built for the post This app could have been a web app, on Stefan Loesch's Substack.

01 Landing page One page that says what a thing does and asks for one action. Copy, steps, features and questions, all in front matter. Open 02 Website A handful of pages under one menu. Each page is a folder holding an index.md. Open 03 Blog Posts as page bundles, a front page of recent posts, an about page and an RSS feed. Open 04 Web app The Topaze Clock. Runs in the browser, installs as an app, works offline, shares by link or QR code. MIT licensed. Open
